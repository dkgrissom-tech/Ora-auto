# Toolstack — automated animal-shorts pipeline

30-day, twice-daily talking-animal shorts for `@toolstack-y4g` on TikTok.
Runs unattended via GitHub Actions. Renders on Replicate. Budget-capped.

## What runs itself

| Time (America/Chicago) | Job | What it does |
|---|---|---|
| 09:00, 17:00 daily | `toolstack-render.yml` | Renders the next queued short, commits the MP4 |
| Sundays 10:00 | `toolstack-weekly-learning.yml` | Scores top 20% winners, appends next week's drafts |

## First-time setup

1. **Repo secret:** Settings → Secrets → `REPLICATE_API_TOKEN` (paste the r8_… token).
2. **Character references:** upload one portrait PNG per character to a public URL (Imgur, S3, or the repo raw URL), then paste that URL into every row's `ref_url` column in `queue.csv`. Reference files live at `brands/toolstack/assets/refs/`.
3. **Kill switch:** Settings → Variables → `TOOLSTACK_RENDER_ENABLED` = `true`. Set to `false` to freeze all renders instantly.
4. **Dry run:** Actions → toolstack-render → Run workflow → dry_run=`true` to preview without spending.
5. **n8n pipeline:** add `toolstack` to the `BRANDS` list in the existing daily post workflow when you're ready to actually publish. Until then, rendered MP4s sit in the repo and nothing hits TikTok.

## Budget guards

See [BUDGET.md](./BUDGET.md). Hard-fails before any API call if projected spend exceeds:
- $0.30 per post
- $1.00 per day
- $30.00 per 30-day window

## Regenerating the queue

Only rerun `scripts/build_toolstack_queue.py` before any renders have marked rows `rendered`. It overwrites the whole file. To extend after renders start, edit the SCRIPTS list at the bottom of the builder and use `weekly_learning.py` instead.

## Manual override

Trigger a single render on demand: Actions → toolstack-render → Run workflow.
Kill everything: set `TOOLSTACK_RENDER_ENABLED=false`.
