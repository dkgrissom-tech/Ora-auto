# Content-generator prompt index

Each prompt generates an **intake-format** post, not a queue file. The generated post must use YAML frontmatter with `kind: post`, a bracketed `platforms` list, full ISO 8601 `scheduled` timestamp with offset, repo-relative media paths, and a `filename`. Pinterest prompts additionally require `pinterest_title` and `pinterest_url`.
